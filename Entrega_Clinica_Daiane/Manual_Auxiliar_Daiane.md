# Manual para Auxiliares

## LJ SmartClinic - Clínica Daiane

**Versão:** 1.0.0  
**Data:** 09/11/2026  
**Público:** Auxiliares de Fisioterapia  

---\n\n### 1. Instruções para Auxiliares de Fisioterapia\n\n#### 1.1 Como Registrar Presença nas Turmas\n\n1. Acesse o módulo **Turmas** pelo menu lateral\n2. Selecione o período desejado (semana/mês)\n3. Localize a turma correspondente\n4. Clique em \"Presença\" ao lado de cada aluno\n5. Confirme a operação\n6. O sistema atualizará automaticamente o contador de presença\n\n#### 1.2 Como Controlar Consumo de Sessões de Pacote\n\n1. Após registrar presença, verifique se o paciente tem pacote ativo\n2. Clique em \"Consumir sessão\"\n3. Selecione o pacote disponível na lista\n4. Confirme a operação\n5. O saldo do pacote será atualizado automaticamente\n6. Verifique se o pacote terminou ou ainda tem sessões\n\n#### 1.3 Como Marcar Faltos\n\n1. Acesse o módulo **Atendimentos**\n2. Localize a consulta do paciente\n3. Se o paciente não comparecer, clique em \"Falta\"\n4. Justifique o motivo se solicitado\n5. O sistema atualizará o relatório de taxas de faltas\n\n#### 1.4 Como Acessar o Histórico de Atendimentos\n\n1. No menu lateral, vá em **Atendimentos**\n2. Use o filtro de data para selecionar o período desejado\n3. Role para baixo para visualizar o histórico\n4. Cada consulta terá seu status indicado por cores\n\n#### 1.5 Como Consultar Planos de Tratamento (Modo Planejado)\n\n> **Nota:** O módulo de tratamentos aparece como \"Funcionalidade planejada\" para fisioterapia, mas a estrutura existe no sistema.\n\n1. Clique no menu **Tratamentos** no dashboard\n2. Mesmo aparecendo como \"planejado\", você pode:\n   - Ver planos existentes do paciente\n   - Criar novos planos (se tiver permissão admin)\n   - Editar planos existentes\n   - Mudar status dos tratamentos (rascunho → em andamento → concluído)\n\n### 2. Atalhos Úteis\n\n| Atalho | Função |\n|--------|--------|\n| `Ctrl` + `T` | Ir para módulo Turmas |\n| `Ctrl` + `A` | Ir para módulo Atendimentos |\n| `Ctrl` + `P` | Ir para módulo Pacientes |\n| `F5` | Atualizar página |\n| `Esc` | Fechar modal/levantar |\n\n### 3. Indicadores que o Auxiliar Deve Observar\n\n| Indicador | O Que Observar |\n|-----------|----------------|\n| **Presença** | Percentual de alunos presentes por turma |\n| **Consumo de Pacote** | Quantas sessões foram consumidas este mês |\n| **Faltos** | Quantos pacientes faltaram e taxa (%) |\n| **Pacotes Vencidos** | Pacotes que terminaram ou estão prestes a vencer |\n| **Planos em Andamento** | Quantos pacientes têm tratamento em andamento |\n\n### 4. Solução de Problemas Comuns\n\n#### 4.1 Tela Vazia em \"Turmas\"\n\n**Causa:** Não há turmas cadastradas para o período selecionado   \n**Solução:** Cadastrar turmas no sistema ou selecionar período diferente\n\n#### 4.2 Botão \"Presença\" está Disable\n\n**Causa:** Usuário não tem permissão `turmas.presenca`   \n**Solução:** Solicitar permissão ao administrador do sistema\n\n#### 4.3 Módulo \"Tratamentos\" aparece como \"planejado\"\n\n**Causa:** Configuração do catálogo para vertical fisioterapia   \n**Solução:** Comportamento esperado - tela será liberada em futura atualização\n\n#### 4.4 Pacote não aparece para consumir\n\n**Causa:** Paciente não tem pacote ativo ou pacote expirado   \n**Solução:** Verificar cadastro do paciente e validade do pacote\n\n---\n\n### 5. Contatos de Suporte\n\n- **Horário:** Segunda a Sexta, 08:00 às 18:00\n- **Canal:** Ticket no sistema ou email da equipe de TI\n- **Emergência:** Ligação direta para número de suporte\n\n---\n\n### 6.
